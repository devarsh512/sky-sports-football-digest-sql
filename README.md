# ⚽ Sky Sports – Football Digest (SQL Project)

## 📌 Project Overview
This project is a **SQL-based football data analysis system** inspired by a **Sky Sports Football Digest**.  
It demonstrates practical SQL skills by designing a structured football database and answering analytical questions using queries.

## 🎯 Objectives
- Design a relational database for football data
- Store teams, players, matches, and statistics
- Perform analytical queries using SQL
- Extract meaningful football insights

---

## 🗂️ Database Description
The database is structured to represent real-world football data and relationships.

### Main Tables
- **Teams** – Club details
- **Players** – Player information and team association
- **Matches** – Match results and scores
- **Competitions** – League or tournament data
- **Statistics** – Goals, assists, appearances, etc.

---

## 🧠 SQL Concepts Covered
- `CREATE`, `INSERT`, `UPDATE`
- `SELECT` with filtering (`WHERE`)
- `JOIN` (INNER JOIN, LEFT JOIN)
- Subqueries
- Aggregate functions (`COUNT`, `SUM`, `AVG`)
- `GROUP BY` and `HAVING`
- Ordering and ranking results

---

## 📊 Sample Analysis Questions
- Which team scored the most goals?
- Who are the top goal scorers?
- Win percentage of each team
- Home vs Away performance comparison
- Most consistent teams across matches
